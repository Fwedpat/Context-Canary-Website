How it works

Models don't forget all at once. Early instructions slip first. Canary plants one and watches whether it's still there.

@canary adds it

Type @canary and your message. The first time, Canary asks what to call you. It then sends your message to Copilot with the instruction as its first lines.

Copilot does the answering

Your message is answered by Copilot itself, with agent mode, its tools, file edits and workspace search. Canary doesn't reply for it.

Added once

The instruction is sent with that one message and never repeated, so it has to survive as the chat grows.

Every reply is checked

Canary reads Copilot's replies from the chat VS Code saves on your machine and looks for your name in each one. Nothing is sent anywhere, and it doesn't keep the text.

A bird that tells you

It sits at the right end of the status bar. Yellow means the last reply followed the instruction, amber means it missed, red means it missed twice in a row. Hover for the counts.

Warnings

When the canary gets worse you get a notification with a button for a fresh chat. It stays quiet while nothing changes.

Three states

The bird follows how Copilot's most recent replies treated the instruction.

Healthy

last reply followed it

The instruction from your first message is still getting through.

Fading

one miss

One slip can be chance. Watch the next reply.

Dying

two misses in a row

Copilot has lost the instruction, and likely other early context. Start a new chat.

What to know

Canary can only work with what VS Code shows extensions. That shapes a few things.

  • Your message shows up twice.First as your @canary message, then as the message Canary passes to Copilot, with the instruction above it. Check that any attachments arrived.
  • It reads a saved-chat format VS Code doesn't promise to keep.If it changes, chats are reported as unreadable, never as misses.
  • The check is a text match, and a miss isn't everything.Your name has to appear as a whole word. A miss shows one instruction was lost, not what else was.
  • It can't tell when Copilot compacts a chat.VS Code doesn't expose that to extensions.
  • Only chats where you used @canary are tracked.Nothing is added to your other chats, and nothing is installed or sent anywhere.
